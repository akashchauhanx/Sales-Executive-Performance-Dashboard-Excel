# Sales Executive Performance Dashboard - Excel

An interactive Excel dashboard designed to analyze sales executive performance, regional sales, and target achievement using sales data.

## 📊 Dashboard Preview

![Dashboard Preview](Dashboard%20Preview.png)

## 📌 Project Overview

This project focuses on analyzing sales performance across different regions and sales executives.

The dashboard provides an interactive view of total sales, target achievement, and performance gaps, helping users compare sales executives and identify performance trends.

## 🎯 Key Analysis

- Sales performance by sales executive
- Region-wise sales analysis
- Total sales comparison
- Target achievement percentage
- Away from target percentage
- Comparison of top and lower-performing sales executives
- Visual analysis using interactive charts

## 🛠️ Tools & Techniques

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Excel Formulas
- VBA Macros
- Interactive Dashboard
- Data Filtering & Analysis

## 🚀 How to Use

1. Download `Sales Executive Performance Dashboard.xlsm`.
2. Open the file using **Microsoft Excel Desktop**.
3. Enable macros/content if prompted.
4. Use the region filters and dashboard controls to explore the sales performance data.
5. Use the charts and tables to compare sales executives and target achievement.

> **Note:** The interactive VBA functionality requires Microsoft Excel Desktop. GitHub does not execute Excel VBA macros directly in the browser.

## 💡 Key Insights

The dashboard enables users to quickly identify:

- Sales executives with higher and lower total sales
- Target achievement levels across executives
- Performance gaps from the assigned target
- Regional differences in sales performance
- Sales contribution of individual executives

## 📈 Dashboard Features

- Interactive region selection
- Sales executive performance tables
- Total sales comparison
- Target Hit % analysis
- Away From Target % analysis
- Bar, Pie, and Line charts
- VBA-enabled dashboard navigation
